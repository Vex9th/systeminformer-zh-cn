# README 精简设计

## 目标

将项目 README 压缩为普通用户可以快速读完的说明，删除冗长的开发细节，同时准确解释修改程序标识的原因和证据边界。

## 内容结构

README 只保留以下内容：

1. 项目简介：System Informer 简体中文社区版，仅提供 Windows x64 无驱动便携版。
2. 修改标识的原因：部分游戏可能根据原版程序名、窗口标题等可识别标志检测程序并强制退出，因此社区版将程序改名为 `sys_info.exe`，并调整部分标题和标识。
3. 有效性说明：这些修改只是降低误检测的尝试，尚未验证是否对具体游戏有效，不保证绕过游戏检测或反作弊系统。
4. 下载和运行：提供最新 Release 链接，说明解压后运行 `amd64/sys_info.exe`。
5. 已知限制：无驱动、不自动更新、只完成 Windows x64 自动化验证，字体、多 DPI 和具体游戏兼容性仍需实机验证。
6. 项目归属：链接上游项目和许可证，说明与官方团队、游戏厂商和反作弊厂商无隶属关系。

## 删除内容

- 删除面向开发者的测试命令和构建过程。
- 删除当前 Release 不提供的 x86、ARM64 使用说明。
- 删除重复、过细或不能帮助普通用户下载使用的描述。
- 删除容易被理解为已经证明兼容游戏或能够绕过检测的表述。

## 验收标准

- README 控制在一屏左右，普通用户无需了解构建流程即可使用。
- 下载路径与当前 Release 实际产物一致。
- 明确写出修改程序名和标题的真实原因。
- 明确写出“是否有效未知”，不作规避反作弊的保证。
- 不修改任何程序行为、资源或构建配置。
