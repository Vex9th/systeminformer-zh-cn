# 进程详情选项卡字体修复设计

## 问题

进程详情窗口使用 `PhPropSheetNew` 创建选项卡。该控件自行创建硬编码字体，没有继承主界面的字体设置。主界面选项卡则使用 `PhTreeWindowFont`。两条字体路径不一致，导致进程详情选项卡文字明显偏小，并可能呈现不同的字体清晰度。

## 方案

只在进程详情窗口中修复字体绑定：

1. 创建进程详情窗口时，按照窗口当前 DPI 调用现有的 `PhCreateTreeWindowFont`，生成与主界面设置一致的字体。
2. 将该字体绑定到进程详情的 `PhTabNew` 控件。
3. 窗口收到 `WM_DPICHANGED` 后，先为新 DPI 创建字体并绑定，再释放旧字体，避免控件短暂引用已释放的 GDI 对象。
4. 窗口销毁时释放专属字体句柄，不修改或释放主窗口持有的字体。

## 范围

- 只修改进程详情窗口的选项卡字体。
- 不改变主窗口或其他工具窗口的默认字号。
- 不增加新的设置项。
- 不修改页面正文、按钮或资源文件。
